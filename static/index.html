How this works & privacy

Runs IPv4 traceroute on this machine: 5 probes per hop, up to 24 hops. Public IPs and your egress IP are looked up using ipwho.is. Private addresses stay local. Map tiles load from OpenStreetMap without an API key; Leaflet loads from unpkg. Results stay in this server’s memory.

Your source marker is your public internet egress, which can be a VPN exit. Routers can ignore probes while forwarding traffic. Hops without locations use schematic map placeholders. Each adjacent pair is styled independently; unknown IPs produce dotted connections. All map links indicate observed route relationships, not physical cables.
